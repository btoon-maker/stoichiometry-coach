Factor bank

Drag a factor into a box, or use its Box button. You can place the same factor again if needed.

How the tool checks you
  • It checks the displayed numerator and denominator of each factor.
  • Equivalent factors are accepted even when they came from a different card or appear in a different box order.
  • It checks orientation so units cancel in the correct direction.
  • The number of slots is set automatically based on your practice type.

Step 3: Multiply the numbers (then divide)

Once your setup is correct, calculate like this: multiply all numerator numbers together, multiply all denominator numbers together, then divide.

Example method:
(numerators) ÷ (denominators)
